# kpod v1 (legacy)

This directory keeps the original Bash implementation for rollback and comparison.

- `kpod-v1` is the Bash CLI previously published via GitHub Gist.
- `publish-gist.sh` is the old gist publisher. It is not used for v2 releases.

kpod v2 is the supported implementation. v2 does not invoke Bash v1.

The installer never deletes `~/bin/kpod-v1` on existing machines.
